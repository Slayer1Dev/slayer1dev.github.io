Sistemas que construí

  1. Integração multi-marketplace

    privado

    Sincroniza catálogo, pedidos e mensagens entre Mercado Livre e Shopee. Trata divergência de estoque entre o que existe no depósito e o que fica publicado em cada canal.

    TypeScript · REST · Webhooks · OAuth

  2. Servidor MCP para marketplaces

    privado

    Expõe operações de marketplace como ferramentas para agentes de IA via Model Context Protocol. Permite que um modelo consulte anúncios, responda perguntas e ajuste preços sob aprovação.

    TypeScript · MCP · Node.js

  3. Daemon de automação

    privado

    Consome eventos de webhook, enfileira e executa ações de forma assíncrona. Sobrevive a reboot, reporta estado por bot do Telegram e escala sem intervenção manual.

    Node.js · Supabase Realtime · systemd

  4. Dashboard operacional

    privado

    Painel de operação em tempo real com autenticação de dois fatores e streaming por SSE. Consome dados de produção direto, sem camada de mock.

    TypeScript · SSE · PostgreSQL

  5. Orquestrador multi-IA

    privado

    Fila de tarefas que distribui trabalho entre modelos de diferentes provedores. Cada job roda isolado em sandbox, é versionado em git e gera diff — nada chega em produção sem revisão humana.

    Node.js · Git · Sandbox · Fila em arquivo

Sobre
